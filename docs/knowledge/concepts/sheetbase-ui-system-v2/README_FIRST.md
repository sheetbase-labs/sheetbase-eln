# Start here

This folder contains two different interfaces that share the same components.

## TanStack Start catalogue

Run `OPEN_UI_SYSTEM.command`.

- URL: http://localhost:3000
- This is the actual TanStack Start application.
- It includes Foundations, Components, Scientific, Patterns and Templates pages.
- The first run installs dependencies and can take several minutes.

## Storybook

Run `OPEN_STORYBOOK.command`.

- URL: http://localhost:6006
- This is the isolated component workbench.
- It is prebuilt and opens immediately.

If the page says “Storybook” in the upper-left corner, you are viewing Storybook, regardless of the port.
