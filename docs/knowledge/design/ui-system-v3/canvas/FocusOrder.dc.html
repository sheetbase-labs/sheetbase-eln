•Menus, popovers and dialogs take focus when they open, keep it inside while open, and return it to the button that opened them.
•Esc closes the top-most overlay. Clicking outside closes menus but never dialogs with unsaved input.
•The focus ring is 2 px focus with a 1 px offset. It is never removed, only moved inside a grid cell.
•Signing asks for the password in the dialog itself; focus starts in the password field.
•Every icon-only button has a label that names the object: “Remove filter: Updated in last 30 days”, not “Remove”.
