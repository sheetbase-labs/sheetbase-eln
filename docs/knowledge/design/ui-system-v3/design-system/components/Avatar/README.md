# Avatar

Initials in a circle for people in the top bar, member lists and comments. No photos in records.

- `Sheetbase.Avatar` with `initials`, `name` (accessible label) and `tone` `accent` | `review` | `ok` | `warn`; `size="sm"` in dense lists. Class `.avatar`.
- Tone separates people in the same view (you, a reviewer, QA); it never carries status.
