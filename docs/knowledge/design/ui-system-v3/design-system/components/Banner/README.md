# Banner and notice

A `.banner` is a full-width strip under the page header for a state of the whole page (offline, reviewing, locked, conflict). A `.notice` is a local message beside the thing it describes.

- `.warn`, `.bad`, `.review` variants use washes, never saturated fills.
- Say what happened and what to do. Keep compliance states factual, not alarming.
- `.tag` marks changes in diffs: `.add`, `.chg`, `.del`.
