# Chart

Scientific plots optimise interpretation: quiet axes, fine gridlines, explicit units, small legends outside the plot area, visible thresholds.

- Series use `series-a`, `series-b`, `series-c` with circle, square and triangle markers.
- Reference lines (`.ch-ref`) are dashed in `text` and labelled with the value and unit.
- Flagged or excluded points are hollow (`.ch-hollow`) and explained in the caption.
- No 3D, gradients, heavy frames or chart-card galleries.
