# Empty state

What a list or panel shows when there is nothing in it. It explains why it is empty and offers the next useful action; no illustrations.

- `Sheetbase.EmptyState` with `title`, `body`, optional `icon`, and actions as children. Class `.empty`.
- Distinguish the three kinds: nothing yet ("No samples in quarantine"), nothing matching ("No projects match “AAV5”" plus Clear search), and not allowed (say who to ask).
- Place it where the rows would be, left-aligned with the table, not centred in the window.
