# Icon

16px stroke icons at 1.4px, drawn in the current text colour. They label navigation and actions and are never decorative.

- `Sheetbase.Icon` with `name` and `size`. `Sheetbase.icons` lists every name.
- Icon-only buttons need an `aria-label` that names the object and action.
- Draw new icons on the same 16px grid with round joins; don’t mix in filled icon sets. No emoji.
