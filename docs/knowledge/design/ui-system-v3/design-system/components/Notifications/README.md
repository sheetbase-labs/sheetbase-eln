# Notifications

The bell in the top bar opens a popover of recent events that concern you. The Inbox is where work is actually done; notifications only point to it.

- Unread items have an `accent` dot, and the bell shows a small dot (`.ib-badge`) while anything is unread. Its label says the count ("Notifications, 3 unread").
- Each row names the person, the action and the record ID, then the time. The whole row is a link to that record.
- Mark all read, Open inbox and Notification settings are always available. Choose channels in Settings, Notifications.
