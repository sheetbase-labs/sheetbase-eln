# Skeleton

Placeholder shapes shown while a page loads, in the layout the content will take. They pulse gently unless the viewer prefers reduced motion.

- `Sheetbase.Skeleton` with `w`, `h` and `r` (radius); class `.sk`.
- Keep real chrome (header, tabs, column headings) and skeleton only the data. Say what is loading in muted text ("Loading experiments…").
- After 10 seconds, replace skeletons with an error state that says what failed and offers Try again.
