Python SDK
# Python SDK 1.4 · reads the snapshot a record cites from sheetbase import Client sb = Client(token=os.environ[ "SHEETBASE_TOKEN" ]) ds = sb.datasets.get( "DS-0311" ).snapshot( "S-15" ) df = ds.to_pandas() # 96 rows, read-only
Install with pip install sheetbase . Signing and approving aren’t available through the API.
Rules
Tokens expire after 90 days at most.
Each call is checked on the server with the owner’s permissions.
Every write is in the audit log with the token name.
Tokens unused for 30 days are flagged to their owner.
