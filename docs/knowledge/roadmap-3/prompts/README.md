# Roadmap 3 Prompts

Roadmap 3 mirrors the Roadmap 2 operating pattern: every capability stream has a task file and a matching reusable agent prompt.

Prompts do not override repository-wide `docs/knowledge/NEXT.md`, the numbered task section, accepted ADRs or current implementation.

Before using a prompt, read:

1. `docs/knowledge/NEXT.md`
2. `docs/knowledge/agent/agent-context.md`
3. `docs/knowledge/agent/workflows.md`
4. `docs/knowledge/roadmap-3/PRODUCT_DIRECTION.md`
5. `docs/knowledge/roadmap-3/PROGRAMME_MAP.md`
6. the full relevant `tasks/<STREAM>.md` and assigned numbered task
7. relevant accepted ADRs and current implementation docs.
