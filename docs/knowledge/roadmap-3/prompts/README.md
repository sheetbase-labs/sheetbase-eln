# Roadmap 3 Prompts

These prompts are reusable starting points for agents assigned to a Roadmap 3 programme. They do not override the repository-wide `docs/knowledge/NEXT.md`, task files, accepted ADRs or current implementation.

Before using a programme prompt, read:

1. `docs/knowledge/NEXT.md`
2. `docs/knowledge/agent/agent-context.md`
3. `docs/knowledge/agent/workflows.md`
4. `docs/knowledge/roadmap-3/PRODUCT_DIRECTION.md`
5. `docs/knowledge/roadmap-3/PROGRAMME_MAP.md`
6. the relevant task section in `tasks/`
7. relevant accepted ADRs and implementation docs.
