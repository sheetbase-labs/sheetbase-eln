## Picking up work

1. Read [GUIDE.md](GUIDE.md), this reconciliation and the original task spec.
   `pnpm roadmap available` shows todo tasks with recorded prerequisites done;
   also inspect partially implemented tasks rather than treating that list as
   the complete next-work order.
2. `pnpm roadmap get <id>` gives the tracker record. Inspect current code and
   the task's dependencies, then set the task and active step to `in-progress`.
3. Use `pnpm roadmap note <id> "…"` to record implementation, PR and acceptance
   evidence separately. Mark a step done only when its complete criterion holds.
4. Run `pnpm roadmap:sync` and `pnpm roadmap:check`. Sync can close a parent when
   its last step is completed; reopen the parent if its actual exit is unmet.
5. Include `.nod/`, CHECKLIST and NEXT updates with the implementation PR.
   No merge, deployment or release follows automatically from tracker status.
