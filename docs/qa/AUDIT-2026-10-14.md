# Sheetbase ELN — independent QA audit

Date 2026-10-14 · application under test: branch `GWP/roadmap-5-qa`, commit `4e230457`, running on
`http://localhost:3000` · identity: auth-free fixture user, Process Development workspace, owner role.

This audit was performed without modifying application code. Every finding below is either
**confirmed** (driven in a browser and observed), **static** (established by reading the source, not
driven) or **unconfirmed** (observed once, not reproducible in the conditions available). The audit
states its own limits in §6 rather than implying coverage it does not have.

## 1. Method

- **Inventory** from the generated route tree: 150 declared paths, of which 65 are page routes and the
  rest are API endpoints; 48 files render dialogs, 26 sheets, 10 dropdown menus, 3 popovers.
- **Driving** through the accessibility tree (role + accessible name), never CSS guessing, with each
  journey asserting an outcome rather than assuming the click worked. Harness: `/tmp/qa3/harness.mjs`
  (open, snapshot, a11y, keyboard, net, perf, shot, resize).
- **Frames** 1440 (desktop), 1024 (laptop), 834 (tablet), 390 (phone).
- **Evidence**: rendered text, computed styles, accessibility facts, failed requests, console errors,
  timings, screenshots in `/tmp/qa3/shots/`.

## 5. What is sound (driven)

- **Technical health, 20 routes** (`/`, `/inbox`, `/search`, `/projects`, `/experiments`, `/protocols`, `/templates`, `/samples`, `/materials`, `/instruments`, `/datasets`, `/analysis`, `/pipelines`, `/models`, `/schedule`, `/scan`, `/settings`, `/settings/audit`, `/help`, `/client-portal`): **0 console errors, 0 failed requests, 0 horizontal overflow**, load 142–383 ms, 31–73 KB transferred per route. `/api/health/live` and `/api/health/ready` both answer 200; `/api/metrics` exposes counters.
- **Frames**: 834 and 390 render every sampled page without layout breakage. At 390 the document reports `scrollWidth 688`, but the page **cannot** be scrolled sideways (`window.scrollTo(999,0)` leaves `scrollX 0`; `body.scrollWidth` equals the viewport) — a measurement artifact of a clipped descendant, **not** a reflow defect (WCAG 1.4.10 is satisfied on the pages checked).
- **Accessibility, 6 pages** (`/`, `/inbox`, `/projects`, `/experiments/new`, `/materials`, `/settings`): main landmark, banner, skip link and a live region on every page; **no** control without an accessible name, **no** image without alt, **no** duplicate ids, **no** positive tabindex, **no** focus trap; every focused element had a visible outline.
- **Adversarial**: double-clicking "Create draft" creates **one** draft (the button shows "Creating…" and the toast names the record); resizing 1440 → 390 → 1440 on a 139-row table leaves overflow at 0; a 484-character title is clipped inside the field with no layout damage; a deep link to an absent import id renders a proper **"Import not found — This import doesn't exist"** state with a route back to the upload step.
- **Buttons** are now one component and one scale: across six pages every control is 28px/13px except the deliberate 24px dense chips, the 30px search field and 36px tabs.

## 6. Limits of this audit (untested areas)

The audit is **not** a full pass, and the gap is concentrated in interactive flows:

- **Driven coverage**: ~45 route loads across the crawl, frames and a11y batches; ~12 interaction journeys (shell toggle, nav, experiment create, double submit, resize, deep links, dialog open attempts).
- **Not driven at all**: create/edit/delete flows in datasets, samples, materials, instruments, models, pipelines, protocols, templates, sheets and analysis; the review and signing flows; imports end to end; settings writes (tokens, signatures, integrations, members); the client portal; help search; the command palette's keyboard contract; every dialog's focus management beyond one attempt; contrast in the **dark** theme; 1024 in most areas; and any screen-reader or zoom-based testing.
- **Environment limits**: the host ran at load averages of 500–930 for much of the audit. Nine parallel reviewers could not be sustained — the shared Chromium accumulated 680 processes and began killing tabs — so five reviewers wrapped up with source-level findings only, and the driven evidence above is the coordinator's own single-driver pass. Screenshot capture timed out under load and succeeded later; two visual impressions (a ghosted projects toolbar, a 298px phone overflow) were **retracted** after re-checking, and one earlier "stuck import" read was retracted after a fair wait showed a correct not-found state.
- Automated checks in this audit are heuristics and were corrected twice during the pass: the theme is authored in `oklch()`, so contrast had to be resolved through a canvas (the first numbers were nonsense), and base-ui's hidden inputs produced false "unlabelled control" positives until they were excluded.

## 7. Recommended automated regression tests

Ordered by the harm they prevent. The first three cover the failures this audit and its predecessor
actually found; the rest close the classes that produced them.

1. **Write-then-reload for every mutating surface** (sheet cell, dataset row, settings field, experiment field, material movement): drive the write, reload, assert the value. A write that reports success without persisting is the highest-harm bug class seen in this codebase, and no test currently covers the reload.
2. **Feedback is visible**: one test per feedback mechanism — a toast renders in the DOM for a representative action from each area (`toast()` had no mounted `Toaster` for 140 call sites and nothing failed). Assert on the rendered node, not on the call.
3. **End-to-end import**: upload a CSV → map → review → assert the dataset's row count increased. It is the flow with the most moving parts and it was structurally broken (a parent route rendered no outlet) without any test noticing.
4. **Permission gates settle**: for every surface gated on a permission read, a never-resolving read must produce a stated failure with a retry, never an indefinite "Checking…". Two such gates have already hung in production code paths.
5. **Component adoption guard** (already added as `src/components/v3/ui/component-adoption.test.ts`): extend it to every duplicated primitive pair and to the button-scale rule — no `Button` call site may carry an `h-`/`px-`/`py-`/`text-` override.
6. **Contrast over the token set**: a unit test that resolves each button/text token pair and asserts the AA minimums, so a token change cannot silently drop a label to 4.4:1.
7. **Every id-bearing route has a not-found state**: a table-driven test that loads each route with a syntactically valid but absent id and asserts a stated failure within N seconds — this closes the dead-end class (run alias, import, review, dataset).
8. **Frame smoke**: for a fixed list of routes, load at 1440/1024/834/390 and assert no unclipped element exceeds the viewport and that the navigation surface is present — this would have caught the phone-navigation hole and the tablet drawer.
9. **Accessibility smoke per route** in the browser suite: landmarks, one H1, no skipped heading level, every control named, no positive tabindex. Cheap to run and it would have caught C2 and the unlabelled-control class.
10. **Dialog contract**: open, assert focus moved inside and the dialog has an accessible name, Escape closes and focus returns to the trigger — applied to the dialogs that mutate state (delete, submit, sign, import, invite).
